Privacy Policy

PixelSynfony Chat. Last updated: November 17, 2026.

What this app is

PixelSynfony Chat is a private tool operated by the owner of the YouTube channel @PixelSynfony. It posts short, scheduled messages in the live chat of that channel's own live stream.

What access it asks for

The app asks the channel owner to authorize access to their YouTube account (the YouTube scope https://www.googleapis.com/auth/youtube) for one purpose only: to find the channel's active live broadcast and to post chat messages on the owner's behalf.

What data we collect

We do not collect, read, store or process any personal data from viewers or chat participants. The app only writes messages; it does not read the chat.

The only data stored is the OAuth authorization token of the channel owner's Google account, kept in a private file on a server controlled by the channel owner, with access restricted to the owner. It is used only to post the messages described above.

Sharing

We do not sell, share, transfer or disclose any data to third parties. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and revoking access

The authorization token is kept only while the app is in use. The channel owner can revoke access at any time at myaccount.google.com/permissions, and can delete the stored token from the server.
